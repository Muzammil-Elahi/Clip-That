# Phase 5: Study Notes and PDF - Context

**Gathered:** 2026-06-26
**Status:** Ready for planning

<domain>
## Phase Boundary

Phase 5 takes the `stitchedTranscript` already stored on the Job record (generated by Phase 3, array of `StitchedTranscriptEntry` with `sourceStartMs`, `sourceEndMs`, `text`) and generates AI-powered study notes via Google Gemini Flash. The notes are stored as a Markdown string on the Job record, delivered to the browser via Supabase Realtime, rendered in the already-scaffolded Notes tab using `react-markdown`, and exported to PDF via `@react-pdf/renderer`. A "Download PDF" button appears in the Notes tab when notes are available. Error handling follows a soft-fail pattern: if Gemini fails, the job completes as DONE with `studyNotes = null` and the Notes tab shows an error message. Video and transcript remain accessible. Schema migration, worker integration, frontend Notes tab, and PDF download are all in scope. Semantic matching (Phase 6) is out of scope.

</domain>

<decisions>
## Implementation Decisions

### AI Provider for Note Generation
- **D-01:** AI provider — **Google Gemini Flash** (`@google/generative-ai` Node.js SDK). Free tier: 1M tokens/day, 15 RPM. Model: Claude's discretion on exact model name (`gemini-1.5-flash` or `gemini-2.0-flash`). Aligns with the free-tier constraint (D-01 from Phase 4 context). `GEMINI_API_KEY` in `worker/.env.local` + Railway environment variable.
- **D-02:** Note generation output format — **Freeform Markdown**. Prompt instructs Gemini to produce well-formatted Markdown with clear sections (e.g., `## Explanation`, `## Key Points`, `## Definitions`). Claude's discretion on exact prompt wording, section order, and tone guidance.

### Notes Storage and Delivery
- **D-03:** Storage column — **`studyNotes Text?`** on the `Job` model (plain Markdown string, not JSON). Requires a Prisma migration. Consistent with the existing string/JSON column pattern on Job.
- **D-04:** Browser delivery — **Supabase Realtime** (same pattern as `stitchedTranscript` and `videoUrl` from Phases 3–4). Add `studyNotes` to the Realtime payload handler and the polling fallback `select()` call in `status-view.tsx`.

### Notes Tab Frontend
- **D-05:** Markdown rendering — **`react-markdown`** with Tailwind Typography `prose` class for styled output in the Notes tab. Renders Gemini's Markdown sections (headings, bullet lists, bold/italic) cleanly.
- **D-06:** Notes tab loading state — When `studyNotes` is null post-DONE (either notes not yet arrived or soft-fail), show a loading indicator in the Notes tab. Transitions to rendered Markdown or soft-fail error message when `studyNotes` updates via Realtime. Claude's discretion on loading UX (spinner, skeleton, or "Generating notes..." text).

### PDF Generation
- **D-07:** PDF library — **`@react-pdf/renderer`**, client-side only via `PDFDownloadLink` component. No new API routes. Notes Markdown already in browser state when Notes tab loads — zero round-trips.
- **D-08:** PDF content — Topic header (`Study Notes: [topic]`) + Markdown notes body + source video URL as footer. Claude's discretion on PDF layout, font choices, and styling within `@react-pdf/renderer` primitives.

### AI Failure Handling
- **D-09:** Failure strategy — **Soft fail**. If Gemini API call fails after 1 retry with exponential backoff, `studyNotes` is left `null`. Job status remains `DONE`. Notes tab shows: "Notes could not be generated. Your video and transcript are still available." Worker logs the error for diagnostics.
- **D-10:** Retry policy — **1 retry with exponential backoff** (~2s delay) on transient errors (rate limit, network timeout). If retry also fails, proceed to soft-fail path (D-09).

### Claude's Discretion
- Exact Gemini model name (`gemini-1.5-flash` vs `gemini-2.0-flash`)
- Gemini prompt wording, note structure order, and study-tone guidance
- Notes tab loading UX (spinner, skeleton, or text placeholder)
- `@react-pdf/renderer` PDF component layout, fonts, and styling
- Worker note-generation module file name (e.g., `worker/src/notesGenerator.ts`)
- Prisma field name (prefer `studyNotes`)

</decisions>

<specifics>
## Specific Ideas

- **Free tier constraint confirmed** — Google Gemini Flash (free: 1M tokens/day) satisfies D-01 from Phase 4. No paid AI API.
- **Soft fail is correct** — Note generation failure should not block video or transcript access. Both are already generated and stored before the Gemini call.
- **`@react-pdf/renderer` over `window.print()`** — User preference; provides actual .pdf file download rather than a browser print dialog.
- **`react-markdown` for rendering** — Pair with `@tailwindcss/typography` `prose` class for clean heading/list styling without custom CSS.
