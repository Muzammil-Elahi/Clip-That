## Phase Goal

**As a** student, **I want to** receive AI-generated study notes about the topic I searched, **so that** I can review key concepts from the video without rewatching it.

<objective>
Add AI-powered study note generation to the worker pipeline. This plan installs the @google/genai SDK, creates the notesGenerator module with Gemini 2.5 Flash, runs Prisma migration to add studyNotes Text? to the Job model, and wires the generator into the worker's processPendingJob() function between buildStitchedTranscript() and the final DONE update.

Per D-01, D-02: Gemini Flash (gemini-3-flash via @google/genai), freeform Markdown output.
Per D-03: studyNotes Text? column — no Prisma cast, plain string | null.
Per D-09, D-10: Soft-fail with 1 retry + ~2s exponential backoff. Missing GEMINI_API_KEY = soft-fail (not fatal).
Per NOT-02/03/04: Prompt instructs Gemini to produce ## Explanation, ## Key Points, ## Definitions sections.

Output: notesGenerator.ts, notesGenerator.test.ts, updated schema.prisma (migration), updated worker/src/index.ts.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → Gemini API | Worker sends prompt over HTTPS; response is AI-generated text. API key must not leak to client. |
| job.topic → prompt | User-typed topic string is interpolated into the Gemini prompt. |
| Gemini response → DB | AI-generated Markdown string is stored as TEXT in PostgreSQL. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | GEMINI_API_KEY | mitigate | Worker-only env var — never in NEXT_PUBLIC_ or client code; follows same pattern as SUPABASE_SERVICE_ROLE_KEY. Add to worker/.env.local and Railway env only. |
| T-05-02 | Tampering | job.topic → Gemini prompt | accept | topic field validated as non-empty string at submission time (Phase 1 Zod schema). Passed as string interpolation into an AI prompt (not code execution). Prompt injection risk is low: worst case is unexpected note content, not code execution or data exfiltration. |
| T-05-03 | Denial of Service | Gemini rate limit | accept | Free tier (15 RPM) is unlikely to be hit for an MVP. Soft-fail strategy means rate-limit errors degrade gracefully to studyNotes=null without affecting video/transcript delivery. |
| T-05-04 | Elevation of Privilege | Gemini response stored in DB | accept | studyNotes is a TEXT column rendered in the browser as Markdown (via react-markdown in Plan 02, which is XSS-safe by default). No eval, no dangerouslySetInnerHTML. No privilege escalation vector. |
| T-05-SC | Tampering | npm install @google/genai | mitigate | Package Legitimacy Audit in 05-RESEARCH.md verifies @google/genai is official Google SDK (github.com/googleapis/js-genai, 17.1M downloads/wk). [VERIFIED: official org repo] — no blocking checkpoint required. |
</threat_model>
