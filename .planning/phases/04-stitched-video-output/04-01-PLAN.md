## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Supabase Realtime | videoUrl is delivered to browser via Realtime; must only reach the owning user |
| Worker → Supabase Storage | Upload uses service role key; must never appear in browser env |
| Worker → YouTube | youtubeUrl already validated by extractYouTubeVideoId(); only validated IDs reach downloader |
| Storage path → Filesystem | jobId is a Prisma-generated UUID; used as storage path prefix with no user-controlled components |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | videoDownloader.ts: youtubeUrl input | mitigate | youtubeUrl already validated by extractYouTubeVideoId() before Phase 4 pipeline starts; only a YouTube video ID (alphanumeric) is passed to ytdl() |
| T-04-02 | Tampering | storageUploader.ts: storage path | mitigate | storagePath = `jobs/${jobId}/output.mp4` where jobId is Prisma UUID — no user-controlled input in path; path traversal impossible |
| T-04-03 | Information Disclosure | SUPABASE_SERVICE_ROLE_KEY | mitigate | Key only in worker/.env.local and Railway env vars; never in NEXT_PUBLIC_ env vars; never in Next.js app; worker is a separate process |
| T-04-04 | Information Disclosure | videoUrl signed URL | mitigate | Signed URL stored on Job row; Job row is RLS-protected (userId filter); only owning user's Realtime channel receives it; URL expires in 24h |
| T-04-05 | Denial of Service | Large YouTube video download | accept | Railway free tier /tmp has limited space; OOM kills the worker process which restarts; acceptable for MVP; document in VERIFICATION.md |
| T-04-06 | Elevation of Privilege | Supabase Storage anon key | mitigate | worker uses createClient(SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY) not anon key; service role bypasses RLS correctly for worker-side writes |
| T-04-SC | Tampering | npm install ffmpeg-static @distube/ytdl-core | mitigate | Both packages APPROVED in Package Legitimacy Audit (RESEARCH.md); ffmpeg-static 8yr/1.2M dl/wk; @distube/ytdl-core archived but APPROVED for MVP; no postinstall scripts flagged |
