# Phase 03 Plan 02: Tab Layout and Transcript Rendering Summary

**One-liner:** Shadcn Tabs component (base-nova/base-ui) with [M:SS] timestamp rendering, topic-based empty state, and status page query fix to show DONE jobs.

## What Was Built

1. **`src/components/ui/tabs.tsx`** — generated by `npx shadcn add tabs`; uses `@base-ui/react/tabs` consistent with the base-nova preset. Exports `Tabs`, `TabsList`, `TabsTrigger`, `TabsContent`, `tabsListVariants`.

2. **`src/types/job.ts`** — added `StitchedTranscriptEntry` interface (mirrors `worker/src/types.ts`) and `stitchedTranscript: StitchedTranscriptEntry[] | null` field on the `Job` interface.

3. **`src/components/status-view.tsx`** — full Done-state replacement:
   - `formatTimestamp(ms)` file-level helper: `[M:SS]` format with zero-padded seconds
   - `initialStitchedTranscript` and `topic` added to `StatusViewProps`
   - Card `className` updated to `cn('w-full', isDone ? 'max-w-2xl' : 'max-w-md')` (Pitfall 4)
   - Done-state placeholder replaced with `<Tabs defaultValue="transcript">` containing Video, Transcript, Notes panels
   - Realtime handler extended to call `setStitchedTranscript(payload.new.stitchedTranscript ?? null)`
   - JSX text nodes used for all user content (T-03-06, T-03-07 — no dangerouslySetInnerHTML)

4. **`src/app/status/page.tsx`** — two fixes:
   - Removed `status: { notIn: ['DONE', 'FAILED'] }` from Prisma query (fixes DONE-job display bug)
   - Added `initialStitchedTranscript` and `topic` props to StatusView JSX
   - Added `import type { StitchedTranscriptEntry } from '@/types/job'`

5. **`src/__tests__/status-view.test.tsx`** — extended:
   - `baseProps` gains `initialStitchedTranscript: null` and `topic: 'machine learning'`
   - Three new test cases: transcript entries with timestamps (STR-02/STR-03), empty state (D-08), three tabs visible (D-06)
