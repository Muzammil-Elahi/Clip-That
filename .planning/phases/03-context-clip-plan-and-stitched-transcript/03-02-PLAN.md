## Phase Goal

**As a** student, **I want to** see a stitched transcript of matching video moments with source timestamps, **so that** I can review exactly what was said about my topic without watching the full video.

<objective>
Build the frontend vertical slice that surfaces the stitched transcript in a tab-based result page. This plan installs the shadcn Tabs component, extends the Job type, fixes the status page query to include DONE jobs, threads `stitchedTranscript` and `topic` through the component tree, and renders the transcript in a `[M:SS] text` format inside the Transcript tab. After this plan the complete Phase 3 user story is deliverable end-to-end.

Purpose: Satisfy STR-02 (user can view stitched transcript), STR-03 (source timestamp references shown as [M:SS]), and the D-06 tab layout requirement. Also closes the DONE-job display bug in the status page (RESEARCH.md Pitfall 1).

Output: Updated `src/types/job.ts`, generated `src/components/ui/tabs.tsx`, updated `src/components/status-view.tsx` and `src/app/status/page.tsx`, and extended `src/__tests__/status-view.test.tsx` with three new test cases.
</objective>
