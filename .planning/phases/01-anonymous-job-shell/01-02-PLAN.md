<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser form → Server Action | User-typed values cross this boundary; Zod validation on the server is the only gate |
| Server Action return → Client state | `{ jobId }` is stored in React state only, never written to URL/localStorage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | Job ID routing | mitigate | `useEffect` on `state.jobId` calls `router.push('/status')` with no query params; job ID stored only in React in-memory state and never serialized to URL or storage (per D-07) |
| T-02-02 | Tampering | XSS via error message display | mitigate | Error messages rendered as React JSX text nodes (not `dangerouslySetInnerHTML`); field error values come from Zod error shape, not raw user input reflected back |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No new package installs in this plan; all packages installed in 01-01 and verified in Package Legitimacy Audit |
</threat_model>
