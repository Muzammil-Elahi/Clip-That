## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → Supabase PostgreSQL | Worker uses WORKER_DATABASE_URL (service-role postgres); bypasses RLS; any code with this URL can read/write all Job rows |
| worker → YouTube caption endpoint | Outbound HTTP to YouTube's internal caption API; response is untrusted external data |
| job.youtubeUrl field → youtube-transcript-plus | YouTube URL from user input is passed to extractYouTubeVideoId before being passed to the library |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | WORKER_DATABASE_URL service-role key | mitigate | Set only in Railway environment variables; never in Next.js NEXT_PUBLIC_* or committed to .env files; .gitignore covers .env.local |
| T-02-02 | Tampering | job.youtubeUrl passed to fetchTranscript | mitigate | Call extractYouTubeVideoId() from worker/src/youtube.ts before calling fetchTranscript(); library also throws YoutubeTranscriptInvalidVideoIdError as a second layer |
| T-02-03 | Elevation of Privilege | Worker service-role bypasses RLS | accept | Worker is the intended and only writer to transcript/clipPlan columns; single-replica, Railway-managed process; no user-controlled code path reaches the worker |
| T-02-04 | Denial of Service | Job stuck in PROCESSING (worker crash mid-job) | accept | Single Railway replica; Railway auto-restarts on crash; job stays PROCESSING but does not block new jobs; stuck-job timeout deferred to Phase 4 per research recommendation |
| T-02-05 | Spoofing | YouTube caption endpoint returns malformed JSON | mitigate | youtube-transcript-plus parses the response; caught errors are mapped via mapTranscriptError() and job is set to FAILED with user-facing message; no raw error propagated to browser |
| T-02-SC | Tampering | npm install youtube-transcript-plus in worker/ | mitigate | Package Legitimacy Audit in 02-RESEARCH.md (lines 124–132) confirms youtube-transcript-plus v2.0.0 is Approved (16,561/wk, github.com/ericmmartin/youtube-transcript-plus); tsx is SUS — not installed; slopcheck passed |
